## 申请策略（来自专利思路.md）

- **方案 A（一件专利）**：主权利要求写第 1 点（等价移植验证方法）或第 2 点（状态机方法），其余作从属权利要求，最后加系统权利要求覆盖整体工具。软件类申请发明专利（方法+系统），实用新型不保护纯方法。
- **方案 B（拆两件）**：①跨语言字节级等价移植与验证方法；②串口通信容错与应答匹配方法（第 2+3+4 点合并）。

## 两条通用撰写红线

1. **不写设备厂家的协议内容**：帧格式（68 L L 68…16）、报文号表、补零压缩算法本身均不可作为发明点，只写"处理这些协议特征的方法"（如"按位置化的链首命令""短应答与数据帧的时间上下文消歧"）。
2. **Qt 原版视为现有技术**：每份文档中"与 C++ 方式的不同点"一节即是对现有技术的区别说明，权利要求落笔时只主张差异部分。

## 实务提醒

- 若工具已对外使用（发给客户、车间公开可见，前端 JS 任何人可查看），可能构成"使用公开"影响新颖性——建议尽快确认使用范围并尽早递交，必要时咨询代理人看能否利用宽限期。
